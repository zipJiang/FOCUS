FOCUS: Active Critic Learning for Long-Horizon Language Model Agents

Learning from intermediate decisions through selective rollouts and refined value estimates.

Credit Assignment in Long-Horizon Tasks

An agent needs to find which town is home to a museum founded by an author. It first investigates the author’s birthplace, then discovers that the museum opened elsewhere and checks its address. It reaches the correct answer after a detour.

This example uses the search, open, and find actions from our BrowseComp-Plus tutorial.

The final reward of 1 does not distinguish the detour from the recovery. This credit-assignment problem grows with task length: one outcome must guide learning across many tool calls and revisions.

A step-wise critic predicts the state value, or expected remaining return under the acting policy. With a binary terminal reward and no discounting, this is the probability of eventual success. Changes in value help identify which decisions made progress.

FOCUS improves these estimates through active critic learning: it selects intermediate states for additional rollouts, then uses their outcomes to refine credit assignment and train the critic. Selecting where to resume limits the generations and tool calls spent gathering this evidence.

Value Refinement from Continuation Rollouts

Save the agent’s context, environment, and browser state while it investigates the birthplace. When the same policy resumes from this state, it may recover or keep pursuing the wrong location. Repeated continuations help estimate its chance of success.

Suppose the critic predicts a value of 0.8. Two continuations return 0 and 1, with a mean of 0.5. Giving the critic’s prediction the weight of one observation yields:

V~=0.8+0+11+2=0.6.\tilde V = \frac{0.8 + 0 + 1}{1 + 2} = 0.6.V~=1+20.8+0+1​=0.6.

As we collect more continuations, their outcomes receive greater weight. Adjust the sliders to explore this balance. Each branch ends immediately with reward 0 or 1; γ=1\gamma = 1γ=1 and κ=1\kappa = 1κ=1.

The critic learns from the critic target Gˉ\bar GGˉ, which captures the continuation evidence. The refined value V~\tilde VV~ combines that evidence with the critic’s prediction to assign credit to the acting policy.

Active Critic Learning

Sampling continuations at every checkpoint is expensive. FOCUS spends its limited rollout budget on states where additional evidence is expected to improve value estimates most.

For example, a checkpoint where the critic predicts success but continuations fail may warrant more sampling than one where predictions and outcomes agree. Allocation depends on this disagreement, outcome variability, and the evidence already collected.

FOCUS selects the candidate with the greatest estimated marginal reduction in mean squared value-estimation error. It also accounts for pending continuations when assigning work to concurrent workers.

The policy and critic remain fixed during collection. The resulting evidence improves current credit assignment and trains the critic for subsequent rounds.

The policy update uses this advantage for the segment’s generated actions, including context-management tokens. Environment observations and conditioning text are masked from actor loss. The critic learns from the fixed continuation-based targets at expanded nonterminal states.

Branching from intermediate checkpoints forms a rollout tree: nodes hold resumable states, and edges hold actions and environment transitions. Value estimates propagate backward through direct-child backups.

Recursive Value Backups

For a state cˉ\bar ccˉ with direct children ch(cˉ)\mathrm{ch}(\bar c)ch(cˉ), average each child’s segment reward and discounted refined value:

V~(cˉ)=κVϕ(cˉ)+n(cˉ)Gˉ(cˉ)κ+n(cˉ).\tilde V(\bar c) = \frac{\kappa V_\phi(\bar c) + n(\bar c)\bar G(\bar c)}{\kappa + n(\bar c)}.V~(cˉ)=κ+n(cˉ)κVϕ​(cˉ)+n(cˉ)Gˉ(cˉ)​.

The count n(cˉ)n(\bar c)n(cˉ) is the number of direct children, and κ\kappaκ sets the critic’s pseudo-observation weight; the experiments use κ=1\kappa = 1κ=1. A terminal node has remaining value zero. An unexplored nonterminal node uses its critic prediction VϕV_\phiVϕ​. Working upward from the leaves lets each child’s evidence inform its parent.

Selection keeps a separate record of directly observed continuation returns. A continuation contributes one observation at its starting node and each new node it visits. Later branching from a descendant adds evidence there; its strict ancestors keep their existing selection counts. The paper denotes these outcome counts by NNN, and direct-child counts by nnn.

Context management is modular. The collection workflow can retain the transcript with AppendOnly() or summarize it with Summarize(...) while preserving task and workspace state. The BrowseComp-Plus tutorial branches at these compaction checkpoints.

Empirical Evaluation

On DeonticBench audit trees, we compare value-estimation error at matched rollout budgets, using reference values estimated from 16 MCTS continuations.

FOCUS reaches lower error as the rollout budget grows. In training experiments, it also improves held-out accuracy on deep search, legal reasoning, and code localization after one epoch at matched per-step generation budgets.
