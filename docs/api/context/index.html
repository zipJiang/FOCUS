Context

Choose what the policy sees at each step. ContextManager owns prompt preparation and context changes; this module supplies transcript retention, exact token continuation, summarization, and their triggers.

ContextManager

Section titled “ContextManager”

Decide what the policy sees. A context manager renders each prompt and, when its trigger fires, compacts the live context. The agent records each compaction’s turns, effect, and context version.

from focus.context import Compaction, CompactionResult, ContextManager, PromptTokens

class KeepRecent(ContextManager):
    trigger = PromptTokens(4096)

    async def compact(self, compaction: Compaction) -> CompactionResult:
        recent = compaction.messages[-4:]
        return CompactionResult((*compaction.seed, *recent), compaction.state)

context = KeepRecent()

This manager restarts from the system prompt and task, plus the last four messages, once the prompt exceeds 4,096 tokens. The agent records the fold and advances the context version. Context managers are shared across branches; keep branch-specific data in the rollout state. A manager can also set the agent’s defaults: max_tokens caps each request, final_answer=False ends a rollout out of steps without a final-answer turn, branch_points() chooses where search may continue, action declares the action kind its decisions need, and check_policy() refuses an incompatible policy at construction. Segments sets all five.

AppendOnly

Section titled “AppendOnly”

Keep the full context between requests: the policy sees the whole conversation, including tool results. This is the agent’s default context manager.

from focus import AppendOnly

context = AppendOnly()

The agent renders the accumulated conversation for every decision and never compacts it. Use Segments(tokens) to continue one assistant response in exact token segments, or Summarize(...) to fold a long transcript. The context manager determines what the policy sees; branch_points separately determines where search may continue.

Segments

Section titled “Segments”

Continue one assistant response in exact segments of at most tokens tokens. Each segment is a decision, so search can branch in the middle of a long answer.

from focus import Segments

context = Segments(256)

Segments(256) caps each request at 256 tokens, exposes each segment boundary for branching, and disables the extra final-answer request by default. It declares token-chunk actions, so the agent normally selects TokenChunkParser; an explicit Agent(parser=...) takes precedence. The policy must accept and return exact token IDs.

Summarize

Section titled “Summarize”

Ask the policy to summarize the transcript, then continue the task from its notes. Summarization runs as a short sub-rollout with the same model and can use workspace tools.

from focus import Summarize

context = Summarize(
    max_prompt_tokens=8192,
    max_reply_tokens=1024,
    max_interactions=4,
)

This manager requests a summary when the rendered prompt exceeds 8,192 tokens. The summary task allows four interactions, with at most 1,024 generated tokens per reply. Use trigger= for another condition, such as StateCounter() after a round of tool calls. Task state and workspace survive compaction. Compaction consumes one outer agent step; its generated turns remain in the history for training. penalty_cap bounds the episode’s total penalty for malformed structured summaries.

AnyOf

Section titled “AnyOf”

Request compaction when any of the supplied triggers fires. After compaction, reset the state tracked by each trigger.

from focus.context import AnyOf, PromptTokens, StateCounter

trigger = AnyOf(PromptTokens(8192), StateCounter())

This example compacts when the prompt exceeds 8,192 tokens or the round’s tool-call allowance is spent. The task state must contain calls_remaining and a positive calls_max.

StateCounter

Section titled “StateCounter”

Request compaction when a task-state counter is spent, then refill that counter from its configured maximum.
