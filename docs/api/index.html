API reference

Run a policy in a task with Agent, then search and prepare training data with Collector. The root package exports what a training run needs; focus.branching, focus.context, focus.priority, and focus.estimation hold independent extension interfaces and their implementations. focus.extend also collects extension interfaces, and focus.backends provides model backends. Each section explains the components and shows how to configure the main choices.

Read Getting to know the library for the complete flow, or Quick start: MATH for a runnable example.

Sample Environments

Section titled “Sample Environments”

Task implementations to reuse or adapt, with shared tools for building your own environments.

  • BrowseComp-Plus — Research questions over a fixed document corpus.
  • DeonticBench — Legal reasoning with searchable statutes and task-specific scoring.
  • LocBench — Locate relevant code in a repository at a fixed revision.
  • Shared tools — Reusable corpus, reading, search, and calculation tools for sample tasks.
