LocBench

Use this sample to study an agent locating code relevant to an issue. The agent investigates a repository with list, grep, and read tools, then submits file or symbol locations. The environment scores those locations against reference labels.

What you supply

Section titled “What you supply”

Provide a case with the issue, repository, base commit, and reference locations, plus a policy. Prepare a Repository at the case’s base commit and pass it to build_world() with a RunConfig. The task prompt exposes the issue; reference changes are used for evaluation.

What to adapt

Section titled “What to adapt”

Adapt RepositoryTool for a different code browser or LocationSubmit for another location format. The metrics module owns scoring, and the environment owns investigation limits and completion. This sample demonstrates code localization; it does not edit the repository or produce a patch.

The reference below covers repository access, task assembly, submission, and evaluation.
