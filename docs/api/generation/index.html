Policy

Section titled “Policy”

Generate model output through a backend or a custom completion function. Its format supplies the codec and the agent’s default action parser.

from focus.backends import Policy

policy = Policy(format=policy_format, complete=complete)

policy_format determines how inputs and outputs are represented. complete returns generated tokens and their log probabilities, which remain attached to those tokens through training-data preparation. The context manager prepares each request. Keep the actor and critic fixed for each tree; the training loop owns model snapshots and batch-age checks. Several collectors can share local execution capacity while calling their own policy objects directly.

PolicyFormat

Section titled “PolicyFormat”

Bind a codec for encoding model input to a parser for interpreting model output.

from focus.backends import PolicyFormat

policy_format = PolicyFormat.resolve(
    "Qwen/Qwen3.5-4B", tokenizer=tokenizer, profile="token_chunk"
)

The codec renders messages as model tokens. The parser interprets output in the model’s format and serves as the agent’s default. resolve() loads the tokenizer and selects a parser from profile, or infers a supported tool-call dialect from the model name. Profiles are qwen_xml, hermes, native, text, and token_chunk. The agent can adapt the parser for text or token-chunk actions; Agent(parser=...) selects an explicit parser. Tool environments need a parser that matches the model’s tool-call syntax. Construct PolicyFormat(name, codec, parser) directly for a custom format.

The tokenizer, chat template, and parser for a known model family.

profile names the parser: "qwen_xml" (Qwen3.5 tool calls), "hermes" (Qwen2.5 tool calls), "native" (API tool calls), "text", or "token_chunk" (exact segments). Without one, the model name selects the tool dialect.

ActionParser

Section titled “ActionParser”

Decode a GenerateResult into the action type consumed by Env.step(). Implement parse() and declare whether the parser supports token-level training or requires native tool calls.

from focus.generation.parsing import ActionParser

class IntegerAction(ActionParser[int]):
    def parse(self, result):
        return int(result.text.strip())

parser = IntegerAction()

Bind this parser in PolicyFormat when your environment consumes integer actions. The parser decodes the generated text; Env.step() defines what that integer does in the task.

Definition
